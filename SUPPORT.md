# Support

- Reproducible bugs: use the bug report form.
- Codex version changes: use the compatibility report form.
- Focused improvements: use the feature request form.
- Vulnerabilities: follow `SECURITY.md` and use a private security advisory.

Include the application version, `codex --version`, macOS version, architecture,
and a minimal reproduction. Remove authentication tokens, prompts, responses,
emails, proxy credentials, and private repository paths.

Support is provided by maintainers and contributors on a best-effort basis.
