## Recording policy

- Record a number only when a public GitHub page, API response, Homebrew
  analytics page, or downstream repository supports it.
- Include the date and source link because counts change over time.
- Do not count CI downloads, maintainer tests, or duplicated retries as users.
- Do not add application telemetry solely to inflate adoption metrics.
- Add downstream projects only with a public dependency or the maintainer's
  permission.

## User reports

If you use the app, CLI, or Core package in a public workflow, open a discussion
or issue describing the environment and use case. Do not include private source
code, prompts, responses, authentication tokens, or proxy credentials.
