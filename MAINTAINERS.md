# Maintainers

## Primary maintainer

- [HZGuoo](https://github.com/HZGuoo): product direction, protocol
  compatibility, security triage, pull-request review, and releases.

## Maintenance policy

- The primary maintainer reviews changes that affect authentication boundaries,
  proxy behavior, App Server protocol handling, exported data, or releases.
- External contributors may own focused issues after scope is agreed publicly.
- New maintainers will be listed here after sustained contributions and mutual
  agreement.
- Security reports follow `SECURITY.md`; public issues and pull requests follow
  the templates in `.github`.

This file documents current responsibility rather than implying a larger team.
